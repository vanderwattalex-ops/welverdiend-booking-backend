Use the same admin token as the booking dashboard. Open this page from the dashboard's "Guest guide" button and you're signed in already.

💬 Send the check-in message

One WhatsApp message with the guide link (opens straight in the browser, nothing to download), the lockbox code and the location. The code is stored privately here and never appears on the guest page.

Afrikaans sends the guide link with ?lang=af, so it opens in Afrikaans. Guests can switch language on the page.

Fill-ins: {name} {unit} {link} {code} {map} {checkin} {wifi} {wifipass} {host} {phone}. WhatsApp shows the photo preview for the first link in the message, so keep {link} above {map}.

📄 Full guide PDF (optional)

Shows a "Download the full guide (PDF)" button at the bottom of the guest page. It opens in the browser. Remove the lockbox code from the PDF before uploading – anyone with the link can open it.

✏️ Guide content

Tap a section to edit it. Changes go live on the guest page as soon as you press Save.

Afrikaans holds only the wording. Photos, phone numbers, Wi-Fi, the address and the driver note are shared – change those under English.
